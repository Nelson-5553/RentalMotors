# 🏍️ RentalMotors

**RentalMotors** es una plataforma web diseñada como proyecto académico que permite a los usuarios rentar motocicletas o poner sus propias motocicletas en alquiler. El objetivo es ofrecer una solución digital sencilla y funcional para facilitar la movilidad y al mismo tiempo generar ingresos extra para los propietarios de motos.

## 📌 Descripción general

RentalMotors fue desarrollado como parte de un proyecto universitario para aplicar conocimientos en desarrollo web full stack. Incluye funcionalidades básicas como navegación, secciones informativas, sistema de autenticación e interacción con una base de datos para gestión de usuarios y reservas.

---

## ⚙️ Tecnologías utilizadas

| Herramienta     | Uso principal                                     |
|------------------|---------------------------------------------------|
| **HTML5**        | Estructura de las páginas                         |
| **CSS3**         | Estilos y diseño responsivo                       |
| **JavaScript**   | Interactividad básica del lado del cliente        |
| **PHP**          | Lógica del servidor y conexión a la base de datos |
| **MySQL**        | Base de datos para usuarios y reservas            |

---

## 🧩 Funcionalidades implementadas

- Página de inicio con bienvenida y descripción del servicio
- Navegación entre secciones: Inicio, Motocicletas, Reservar, Iniciar sesión
- Autenticación de usuarios (login)
- Sistema básico de reservas de motocicletas
- Interfaz amigable y diseño con curva inferior visual
